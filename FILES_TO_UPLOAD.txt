================================================================================
C语言学习网站 - GitHub Pages 部署文件清单
================================================================================

你需要上传到 GitHub 仓库的文件（共 4 个）：

1. index.html              (216 KB)
   - 主网站文件
   - 包含所有功能：学习进度、课程、题库、错题本、代码练习
   - C 语言解释器已内嵌在此文件中
   - C++ 编译器从 CDN 动态加载

2. .nojekyll               (0 B)
   - 空文件
   - 告诉 GitHub Pages 不要使用 Jekyll 处理
   - 必须保留，否则可能导致页面 404

3. README.md               (3.4 KB)
   - 项目说明文档
   - 显示在 GitHub 仓库首页
   - 可选，但建议保留

4. DEPLOYMENT_GUIDE.md     (5.7 KB)
   - 详细部署指南
   - 可选，可以删除
   - 如果删除，不影响网站运行

================================================================================
不需要上传的文件：
================================================================================

- wasm-compiler/ 目录
  原因：C 语言解释器已完全内嵌在 index.html 中，不需要外部文件

- server/ 目录
  原因：这是 Node.js 后端方案，已废弃，不需要

- 其他 .md 文件（INSTALL.md, QUICKSTART.md, TEST.md 等）
  原因：这些是开发文档，不影响网站运行，可选上传

================================================================================
文件结构：
================================================================================

你的 GitHub 仓库应该是这样的结构：

c-learning/
├── index.html
├── .nojekyll
├── README.md
└── DEPLOYMENT_GUIDE.md

================================================================================
部署步骤摘要：
================================================================================

1. 在 GitHub 创建新仓库（公开）
2. 上传上述 4 个文件到仓库根目录
3. 进入 Settings → Pages
4. Source 选择 "main" 分支，文件夹选择 "/ (root)"
5. 点击 Save
6. 等待 1-2 分钟
7. 访问 https://你的用户名.github.io/仓库名/

================================================================================
验证部署成功：
================================================================================

访问你的 GitHub Pages 链接后：

1. 应该能看到网站首页
2. 点击"代码练习"
3. 选择"C"语言，输入代码并运行
4. 选择"C++"语言，等待编译器加载（首次 20-30 秒）
5. 输入 vector 测试代码并运行

如果都能正常工作，说明部署成功！

================================================================================
重要提醒：
================================================================================

✓ C 语言：立即可用，无需加载
✓ C++ 语言：首次使用需要从 CDN 加载编译器（约 20-30 秒）
✓ 必须在 HTTPS 环境下使用（GitHub Pages 自动提供 HTTPS）
✓ 支持 Android 平板 + 夸克浏览器
✓ 所有数据保存在浏览器 localStorage 中
